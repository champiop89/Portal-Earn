# Portal-Earn 🎮💰

Nowoczesny portal łączący wypełnianie ankiet z ofertami gier, umożliwiający użytkownikom efektywne zarabianie i śledzenie postępów.

## 🚀 Funkcjonalności

- ✅ **Rejestracja i logowanie** - Bezpieczna autoryzacja użytkowników
- ✅ **System ankiet** - Wypełnianie ankiet i zarabianie punktów
- ✅ **Oferty gier** - Integracja promocji i ofert gier
- ✅ **System zarabiania** - Punkty, premie, wycofywanie zarobków
- ✅ **Profil użytkownika** - Śledzenie postępów i historii
- ✅ **Panel administracyjny** - Zarządzanie ankietami, grami i użytkownikami
- ✅ **Responsywny design** - Działa na wszystkich urządzeniach

## 📋 Stos technologiczny

### Frontend
- **Next.js 14** - Framework React
- **React** - UI Components
- **Tailwind CSS** - Styling
- **TypeScript** - Type safety

### Backend
- **Node.js** - JavaScript runtime
- **Express.js** - Web framework
- **PostgreSQL** - Relacyjna baza danych
- **JWT** - Autentykacja
- **Bcrypt** - Haszowanie haseł

### Deployment
- **Vercel** - Frontend hosting
- **Railway** - Backend hosting i baza danych

## 🛠️ Instalacja

### Wymagania
- Node.js 18+
- PostgreSQL 14+
- npm lub yarn

### Szybki start

```bash
# Backend
cd backend
npm install
cp .env.example .env
npm run dev

# Frontend (w nowym terminalu)
cd frontend
npm install
npm run dev
```

Aplikacja będzie dostępna na http://localhost:3000
